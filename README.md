# Weather App

A weather application built using HTML, CSS and JavaScript that displays current weather information for different cities.

# Live Demo

[Click here to use the Weather App](weather-app-six-topaz-38.vercel.app)

# Features

- Search weather by city name
- Display current temperature
- Display humidity and wind speed
- Weather icons based on weather conditions
- Error handling for invalid city names and network issues

# Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo API

#  Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
